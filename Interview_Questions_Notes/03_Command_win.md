# VS Code Commands - Windows

A comprehensive reference of commonly used VS Code commands and keyboard shortcuts for **Windows**.

---

## General Commands

| Command / Action                  | Windows Shortcut          |
|-----------------------------------|---------------------------|
| Open Command Palette              | `Ctrl + Shift + P`        |
| Quick Open (Open File)            | `Ctrl + P`                |
| New Window                        | `Ctrl + Shift + N`        |
| Close Window                      | `Alt + F4`                |
| Open Settings (UI)                | `Ctrl + ,`                |
| Open Keyboard Shortcuts           | `Ctrl + K, Ctrl + S`      |
| Open User Settings (JSON)         | `Ctrl + Shift + P` → `Open User Settings (JSON)` |
| Toggle Full Screen                | `F11`                     |
| Zoom In                           | `Ctrl + =`                |
| Zoom Out                          | `Ctrl + -`                |
| Reset Zoom                        | `Ctrl + Numpad0`          |
